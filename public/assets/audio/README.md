# Âm thanh tuỳ chọn

Game tự tổng hợp mọi âm thanh, không cần file nào ở đây.

Nếu bạn **có quyền sử dụng** một bản thu (tự thu, hoặc đã được cấp phép), đặt nó tại:

- `chanh-dien.mp3` — phát thay cho giọng tụng tổng hợp mỗi 3 phút trong Chánh Điện.

Không đặt nhạc hay bản thu có bản quyền mà bạn chưa được phép dùng.
